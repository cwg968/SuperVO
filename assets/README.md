# 演示素材

均为本项目 Pangolin 窗口的真实 TensorRT GPU 运行录屏，使用双目惯性滑窗、uniform、resolve，无回环。

| 文件 | 数据序列 | 展示内容 |
|---|---|---|
| `euroc-room.gif` | EuRoC V1_01_easy | 实测特征跟踪与房间地图增长 |
| `euroc-machine-hall.gif` | EuRoC MH_02_easy | 机库建图与观察相机环绕 |
| `tumvi-handheld.gif` | TUM VI room1，512_16 | 手持运动中的特征跟踪与地图 |

GIF 为连续录屏片段，896×536、10 帧/秒、8 秒循环，按 2 倍录屏速度播放，不作为实时性能评测。
绿色表示当前实测特征／地图点，蓝色为累计稀疏地图，橙色为轨迹；历史地图点保留最近估计，未经过全局 BA。
环绕仅改变观察相机视角，不改变估计轨迹。原始录制、轨迹、日志与编码中间文件未纳入素材目录。
